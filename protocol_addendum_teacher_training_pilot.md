## Paper correspondence

The verified source is [arXiv:2607.22629v3, §3 Eq. (1)–(4), Appendix A.3](https://arxiv.org/html/2607.22629v3), accessed 2026-10-26. The paper defines `k_alpha=floor(alpha*m)`, gives the frozen think-mode teacher context `x,z_<=k_alpha,y_<t`, samples `y` on-policy from the no-think student, and minimizes per-response-position full-vocabulary `D_KL(pi_S(.|x,y_<t) || pi_T(.|x,z_<=k_alpha,y_<t))`; gradients update only the student. At α=0 the teacher sees no trace prefix; α=1 sees the full trace. Appendix A.3's SFT target is the fixed teacher suffix `z_(k_alpha+1:m)` followed by solution `s`, under student prompt `x`; this remains an off-policy SFT proxy. The paper used larger Qwen3-4B/8B models and math/graph coloring, so this small synthetic Qwen3-1.7B decision pilot is not a reproduction of the paper's reported experiment. The repository search did not establish an author-owned official implementation.

The implementation includes Qwen's generated `<think>` token inside the full assistant response after `assistant\n`. For the paper's teacher context `x, z_<=kα`, training must restore `<think>` before injecting the trace prefix because the generation prompt is only the prefix through `assistant\n`. The no-think student prompt ends with an empty `<think>\n\n</think>\n\n` block; answer and trace-suffix targets are scored from the exact student prompt boundary and use raw teacher trace/solution token IDs. The student teacher prompt renders `enable_thinking=False`; the teacher condition renders `enable_thinking=True`.

## Teacher gate and collection

- A dev-only stratified diagnostic of 120 existing dev items (20/family; seed `20281027`) with exact existing prompt, checkpoint revision, think template, temperature 1, top-p 1, top-k disabled and `max_new_tokens=768` produced 57 closed traces, 53 correct answers and 39 traces passing the existing executable grounding screen. The preregistered diagnostic threshold was at least 50% screened among closed traces: observed 39/57 = 68.4%. Completion was only 57/120 = 47.5%; overall screened yield was 39/120 = 32.5%, and the conditional result may be selection-biased. This is a feasibility gate only, not evidence of MSD efficacy.
- Use only the first 600 rows of the pre-existing, solver-verified `data/train.jsonl` (actual family counts: rules 107, routing 112, time/numeric 109, multihop 89, evidence 95, intent 88; no dev, pilot-holdout, v2, or v3 rows). Generate one teacher response per item with the same frozen model and settings, cap 768, and screen strictly: closed `<think>` block, exact solver-correct final label, at least two nonempty reasoning lines, and all symbolic/numeric atoms grounded in the prompt or solver certificate. Save accepted and rejected records; never silently repair outputs. The original screen is unchanged in this pilot even though it is known to reject some legitimate arithmetic intermediates; report accepted family counts and the resulting coverage limitation. Only the accepted train rows are available to any training condition.
- Split teacher generation across two independent single-GPU replicas by deterministic row index. Per-item sampling seeds are derived from `20281028 + original_train_index`. Merge accepted records by original train index. No shared model files or environment changes.
