# Implementation smoke and mask-boundary addendum

Frozen 2026-10-26 Asia/Shanghai before full train-only teacher collection. This addendum records implementation checks and clarifies code semantics; it does not alter the original preregistration, the 600-row training-only data policy, or any held-out selection rule.

The paper body is arXiv:2607.22629v3 §3 Eqs. (1)–(4), training details §4, and Appendix A.1/A.3. The author describes using `verl`, but an author-owned public repository containing the experiment implementation was not found in the paper or artifact searches performed for this run. Thus this is a transparent equation-level implementation, not a code reproduction. For α, the code uses `k=floor(alpha*m)`. MSD samples student no-think rollouts; computes full-vocabulary `KL(pi_student || pi_teacher)` at every student response token, summed across response positions and averaged across examples; only student LoRA weights receive gradients. Teacher is a frozen same-revision copy. α=0 teacher context is byte-identical to the student no-think prompt; partial α injects exactly the first k raw trace token IDs inside the empty Qwen think block and leaves that block open; α=1 supplies all trace IDs and the closing marker. The same sampled response IDs are scored under both contexts.

The SFT proxy follows Appendix A.3's suffix target `z_{k+1:m}` followed by solution `s`: for α<1, the target includes the remaining trace and Qwen think delimiters; for α=1 only the solution is trained under the direct/no-think prompt. The loss is standard response-token cross entropy and is explicitly labeled an off-policy SFT proxy. This differs from the full paper's model scale, task domain, infrastructure, optimizer budget, rollout count, context lengths, and training duration.

Before launching collection, local `py_compile` passed on all run scripts. Server-side smoke used six train rows only: 5/6 teacher traces closed, 5/6 answers were exact, and 3/6 passed the existing grounding screen; this tiny sample is only a pipeline check. A one-row, one-update smoke passed for answer-only SFT; teacher-suffix SFT α=0/0.5/1; and MSD α=0/0.5/1. The initial MSD mask fixture was corrected and rerun: α=0 exactly matches the student context, partial α leaves the think block open, α=1 includes the closing marker. On one identical initialization, α=0 initial KL was observed as 0.0 (three rollout tokens); α=.5 and α=1 losses were finite. Smoke dev used only one item and is not reported as performance evidence.

The unopened test is v6, with identity recorded in `protocol_addendum_v6_unopened_test.md` and `results/unopened_test_v6_attestation.json`. The prior v5-named artifact was disqualified by a local hash/size mismatch before evaluation. Do not inspect or evaluate v6 until all training and dev checkpoint selection are frozen.
